Point Vernon walks and cycling

A paved 5 km foreshore return

Start opposite 138 The Esplanade, near Wattle Street, and follow the Point Vernon Foreshore Reserve parkrun course out and back. The course is 5 km entirely on a permanent paved shared path.

Allow about 60–90 minutes for 5 km at an easy walking pace, plus stops. This is a planning estimate. Return to the same start; the organiser’s course map shows the turnaround.

A shelter, bicycle rack and water bubbler are about 200 metres north of the start; a unisex toilet is about 200 metres south. Use the parkrun guide for the Saturday event.

A shorter walk from the same start

For 2 km in total, walk 1 km along the same path and return. Use your own distance measure for the turnaround and allow about 25–40 minutes, plus stops.

For a short bay-view stroll, choose Gatakers Bay or The Gables as a base and return to your starting place. Find the named stops.

Prams, mobility and shared space

The measured course is paved; parking approaches, crossings and gradients matter too. ESA Park has accessible park facilities for another starting option. Carry water and sun protection, give pedestrians room, and slow before passing on a bicycle.

If you leave the path

These beaches are unpatrolled. Check the tide before walking onto the rock flats; keep a clear route back and stay clear of boat ramps.

Use signed dog boundaries for a walk with a dog.
