# Portfolio content boundaries

These rules keep PointVernon.com focused and prevent duplication with Visit HB and Hervey Bay Kids. Cross-link to the site that owns the visitor’s next question instead of reproducing its full guide.

| Topic or search intent | Owning site | PointVernon.com treatment |
| --- | --- | --- |
| Exact Point Vernon beaches, access points, foreshore rules, parks, history, local services and property checks | PointVernon.com | Publish the complete source-checked guide |
| Regional Hervey Bay accommodation, whale tours, K’gari planning and broad visitor itineraries | Visit HB | Give only Point Vernon-specific context, then hand off |
| Regional family activities, schools, care, playground round-ups and family event discovery | Hervey Bay Kids | Keep exact Point Vernon facts; hand off broader family research |

## Editorial test before creating or expanding a page

1. Is the page primarily about an exact Point Vernon place, rule, access decision, service or documented local story? If yes, PointVernon.com can own it.
2. Would the page remain substantially the same if “Point Vernon” were replaced with “Hervey Bay”? If yes, it probably belongs on Visit HB or Hervey Bay Kids.
3. Does another portfolio site already answer the broader intent well? If yes, add only the local information gain and link to the owner.
4. Can one canonical page be maintained more accurately than three similar pages? If yes, keep one owner and use descriptive cross-links.

Quarterly, compare page inventories across the three sites. Record any intentional overlap, its distinct audience and the unique information each version adds.
